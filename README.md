# Personal Finance System (CLI)

This is a simple command-line application I built to help track daily expenses and understand spending habits.

I wanted something lightweight that runs in the terminal and stores data locally without needing a database.

## Features

- Add and store expenses
- Save data using JSON
- View all recorded expenses
- See spending grouped by category
- Simple interactive command-line interface

## Tech Used

- Python
- JSON (for storing data)

## How to Run

1. Clone the repository  
2. Navigate into the project folder  
3. Run the main file:

   python main.py

- Organize a small project and make it usable from the command line
